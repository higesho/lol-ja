# ランズ・オブ・ロア シリーズ 日本語化プロジェクト

ランズ・オブ・ロア（Lands of Lore）シリーズを日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。
GOG.com で販売されている版を対象に、第1作から順に日本語化していきます。
開発元・販売元とは関係ありません。

- サイト（作品の紹介・入れ方）: https://higesho.github.io/lol-ja/
- ダウンロード: [リリース](https://github.com/higesho/lol-ja/releases)
- ウルティマ シリーズの日本語化: https://higesho.github.io/ultima-ja/
- マイト・アンド・マジック シリーズの日本語化: https://higesho.github.io/mm-ja/
- D&D シリーズの日本語化: https://higesho.github.io/dnd-ja/
