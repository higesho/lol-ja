Lands of Lore: The Throne of Chaos

ランズ・オブ・ロア 日本語化MOD

GOG.com 版の「Lands of Lore: The Throne of Chaos」（DOS 版）を日本語で遊べるようにする、非公式のファンメイドMODです。 人物の会話、本や手紙、品物・呪文・地名の名前、メニューの文字、オープニングと歴史の語り、エンディングの台詞まで、ゲームの中の文章を日本語にしています。 声は英語のままで、声と一緒に日本語の文字が出ます。 ゲームのフォルダにファイルを置くだけで日本語になり、外せば英語に戻ります。

ダウンロード（GitHub）

どんなゲーム？

ランズ・オブ・ロアは、1993年にウエストウッド・スタジオが発表したロールプレイングゲームです。

グラッドストーンの王国で、リチャード王が魔女スコシアの企てに立ち向かう勇者を求めます。 スコシアは古代の「冥界の仮面」を手に入れ、姿を自在に変える力で王国を脅かしていました。 プレイヤーはアクシェル・マイケル・キーラン・コンラッドの4人から1人を選び、森や洞窟、町や塔を巡って、旅の途中で出会う仲間とともにスコシアに挑みます。

画面は一人称の立体迷路で、怪物とは移動の画面のまま時間の流れの中で戦います。 GOG.com で販売されているのは、人物の会話に声が付いた DOS の CD 版です。

入れ方

  1. ダウンロードした LandsOfLore_JP.zip の中身を、ゲームのフォルダ（LOLCD.EXE があるフォルダ）にそのまま展開します。
  2. ゲームのフォルダの中の DOSBOX フォルダに、winmm.dll と LOLJP フォルダが増えれば完了です。元からあるファイルを上書きすることはありません。
  3. いつもどおり GOG Galaxy やショートカットから起動します。

ゲームのファイルは書き換えません。

外し方

  • DOSBOX フォルダから winmm.dll と LOLJP フォルダを消します。
  • 一時的に英語で遊びたいときは、DOSBOX\LOLJP\loljp.ini の Enable=1 を Enable=0 に書き換えます。

セーブデータは英語版と共通です。日本語版と英語版を行き来しても、続きから遊べます。

遊ぶときの注意

  • ゲームの言語は English のままにしてください。セットアップで French や German を選ぶと日本語になりません。
  • ゲームの設定の「文字は」は、起動するとオンになります。オフにすると、会話が声だけになります。
  • セーブの名前は英字で入力します。
  • 日本語化の前に始めたセーブデータでは、仲間の名前が英語のまま出るところがあります。新しく始めると日本語の名前になります。
  • タイトルのロゴ、呪文を覚えたときの呪文名の絵、方位磁石の文字など、絵として描かれた文字の一部とスタッフロールは英語のままです。
  • セットアップ（Dosbox Configurator から開く設定画面）は英語のままです。
